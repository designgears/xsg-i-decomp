# Worker lessons (gcc 2.96 EE, Xenosaga decomp)

What earlier subagents (Muse Spark + Opus) learned when they took functions from 0.6 to 0.99. Read this before you start editing.

## Edits that moved the score (with examples)
- **Address arithmetic and CSE.** Write `p_off` and `b_off` as explicit locals so gcc stops merging `off+base`. In sefAllocScheduler this took the score from 0.61 to 0.83.
- **`addu` operand order.** If a diff shows `addu a,b,c` where the target has `addu a,c,b`, try a `(int)base` cast on one operand. In sefAllocScheduler this fixed both addu operand orders.
- **Splitting modulo/increment expressions.** `nxt = i+1; nxt %= 0x80;` compiles differently from `nxt = (i+1)%0x80`.
- **Globals typed `int` instead of narrower types** can stop gcc hoisting loads early.
- **Single exit with goto.** Write `if (c==0) goto done; ... done: return p-msg-1;` with the return at the end, and drop the redundant `start` var. This fixed the prologue order and the delay-slot layout in MSG_getSize (0.79 to 0.93).
- **Order of updates inside a case.** In MAP_updateUnitSpecialSymbol, swapping `position.y` and `rotation.y` raised the score (0.906 to 0.9125). If the target loads globals in order X then Y, write the C in that order too.
- **Typed struct access instead of a raw global.** `((CardPosWork*)CardPos)->r[i].y` produced the target's `addu v0,v0,s1`. Follow how matched siblings in the same TU access the same data.
- **u64 vs u32 locals, swapping i/j, copying an already-matched sibling's style, per-case store+break instead of a shared goto, reordering error paths, a separate `unsigned char *src` copy pointer.** Each of these closed a near-miss at least once.
- **`volatile`** stopped two read-modify-write ops on one field (`|=1`, `|=0x20`) from merging into one.
- **Statement order around `lw` loads.** Hoisting `packed = src[2];` above `size = src[1];` fixed a `move a3,a0`.
- **Store duplicated into branches.** If the target has a store as the FIRST insn at the label where if/else branches rejoin and ours sinks it later, move the assignment that follows the if/else chain into the end of every branch (gcc cross-jumps the identical tails after scheduling). The reverse (hoisting identical branch-tail stores after the chain) also happens. Matched DrawRadarInfo. trick_sweep family `dup_tail_store`.
- **Register rotations can be a priority near-tie.** s-reg rotations between values live across a loop/calls come from global alloc order: priority = floor_log2(refs) * refs / live_length (insns). Diagnose: `try_fn.try_function(..., keep=True)`, take the kept `cand/*.i`, run the TU's ee-gcc `-O2 -S -dl` (+ the TU's `-G` flag, see compile_edge / tools/tu/cc_tu.sh), read `Register N used R times across L insns` in the `.lreg` for your function (user-var pseudos are numbered params first, then scalar locals in declaration order). The value that must get the earlier s-reg needs the higher priority: to lower a value's priority move its last use later (or an independent statement into its live range); to raise it move its def later / last use earlier. Matched DrawRadarInfo. trick_sweep family `regalloc_tie` does this automatically when the diff is register-only.
- **Branch-likely bit (`bnezl` vs `bnez`, same delay insn).** Reorg's annul choice depends on a label / jump at the fall-through: try `goto z; z: return 0;`, a `return` before a label that is fallen into, or `ret = K; goto end;` for equal constant returns. trick_sweep family `fallthrough_label`; triage tags it `branch_likely` (permuter gets label/goto weights). Matched srsAnalyzeEftNo with a redundant re-store of the already-written out-param before the early return (`*effectCategory = 0xE; return 0;`) — forces forward plain `bnez` + separate return-0 block instead of inverted `beqz` / `bnezl`. Still useful for CGPChkOpePlayable-style leftovers.
- **Two independent ALU insns swapped before stores to a stack array** (`buf[0]`, `buf[1]` from `/` and `%`): sched2 priority comes from trap_if (div-by-zero) anti-deps on earlier stores. Hoist the later division into a temp before the earlier store, or swap the stores with a temp. trick_sweep family `div_hoist`. Not yet proven (_time_disp).
- **Wrong comparison (branch opcode differs, not an inversion).** If one branch differs only in its condition and the pair is NOT a simple inversion (e.g. target `bgez` vs ours `blez`, not `bgez` vs `bltz`) on the same operands, the C condition itself is wrong (m2c / an agent wrote `>= 1` where the code means `< 0`). Do not chase it with scheduling tricks: read the target branch (`bgez x` = the code tests `x >= 0` / `x < 0`, `blez/bgtz` = `x <= 0` / `x > 0`) and rewrite the comparison (operator, constant k-1/k/k+1, or the then/else arms). This is a semantic bug, so check it anywhere in the diff, not just in near-misses. Matched main/srs/fileLoad (0.9891 -> match: `_nRead >= 1` -> `_nRead < 0`). trick_sweep family `cmp_fix` (diff-gated, strong prior; `trick_sweep.py --all-pending --families cmp_fix` scans every pending body).
- **One store moved, no register changes: sched1 register-weight tie.** sched1 (`rank_for_schedule`) breaks equal-priority ties on register weight (sets minus REG_DEAD deaths) before insn order, so the insn holding a variable's LAST use wins. Diagnose: `trick_sweep.sched_ties(unit, tu, name, text)` compiles the kept .i with `-dS -dR -fsched-verbose=6` and lists sched1 decisions where the chosen insn beat a ready insn of equal priority, with both REG_DEAD sets. Fix by moving where the stored variable dies: re-read the stored lvalue instead of the variable afterwards, split/reorder chained stores `a = b = v;`, move statements that use it, a temp copy, int/unsigned/float type. trick_sweep family `sched_weight` (EtherTreeBlackDraw: not matched yet).
- **Two adjacent insns swapped next to a movz/movn: early if-conversion.** Equal priority in sched2 inherits sched1's order; if the min/max/clamp is already an `(if_then_else)` in the `.sched` (sched1) dump, pre-reload ifcvt converted it too early, while the original likely stayed a branch until post-reload ifcvt (ce2). `sched_ties` reports `cmov_sched1` / `cmov_sched2` counts. Rewrite the min/max (`a<b?a:b`, `if (x>K) x=K;`) as if/else statements, default-then-overwrite, a temp in the arm, goto/label, unsigned compare. trick_sweep family `de_ifcvt` (SsdAddWaveData: none of these kept the movz out of sched1 yet).
- **Address/constant inits reordered right before a loop label: loop-preheader tie.** The strength-reduced address inits + countdown are ordered by sched1's tie-break, which depends on what is live after the loop. Vary it: copy the limit into a fresh variable, use another lock-step counter as the exit test, `i = n;` / reset after the loop, a countdown variable. trick_sweep family `loop_live` (subMWModeExSet: speculative, no gain yet).
- **Wrong constant copied from a sibling.** If the only differing words are the same `lui`/`ori`/`addiu`/`li`/`andi`/`slti(u)` (same regs) with another immediate, the body kept a sibling's constant (clone_twins / copied bodies especially). Rebuild the target's full value (lui hi<<16 + the addiu/ori lo consuming it) and put it in the C literal. Matched main/end_print/subPrintRibbon (`0x20654000` -> `0x20A64000`). trick_sweep family `const_fix` (diff-gated, strong prior; also load/store offsets).
- **`int` function falling off its end: make it `void`.** An int function with no `return <expr>` gets a clobber/use of v0 at the end that reorders the last block in sched2. If the target's final block leaves no value in v0 (v0 only used as scratch), declare it `void`; a conflicting `static int f(...);` forward declaration in the TU must be flipped first with `verified_edit.py` (byte-identical gate; it fails if a caller uses the value). Reverse case: a void body whose target ends with v0 set -> `int` + `return` of the last call/value. Matched ov12/rg_camera/_SetVersion3Extent. trick_sweep family `void_ret` (evaluates with a patched TU through `try_function(overrides=...)`, applies the declaration flip with verified_edit before integrating).
- **`.lit4` / `.lit8` constants are literals, not externs.** `extern float D_xxx` for a value that lives in a `*.lit4.s` / `*.lit8.s` data file (build/main/asm/main/data) loads through a pseudo SET (+1 register weight) and changes sched1's order; write the exactly round-tripping literal (`65535.0f`, `1.04719758f`). try_fn then reports `match_after_link` with `lit_literal` (GPREL16 -> D_xxx vs LITERAL -> .lit4): run `integrate.py --skip-try`, the carve places the literal. Matched main/game/checkTalk; MenuShopModelDisp (a delay-slot order diff, lwc1 vs move, not a constant diff). trick_sweep family `lit_inline` (also for m2c's `extern f32 D_xxx`).
- **Zero-extend placement (`addiu; andi 0xffff; sltiu`).** Every simple form lands elsewhere: unsigned compare drops the andi, `(unsigned short)(x-C)` becomes `li 0x8fec; addu`, signed keeps andi but uses slt. Try forms combine cannot see through: the masked value in a temp / statement expression, a union u16/s16, a 16-bit bitfield, used twice. trick_sweep family `zext_form` (InitMapTrap: speculative, low prior). Pre-screen expression variants with `snippet.py` (compiles a standalone snippet with the TU's ee-gcc flags in ~0.3 s) before spending full try_fn runs.
- **Struct field stores scheduled too early: alias set.** A pure reorder (same insns) where `sw`/`sh`/`sb` through a struct pointer moves earlier and the block also loads a global of the same scalar type: the int store may alias e.g. `int camMode` loaded right after, so sched2 adds a memory dep edge store -> global load -> call that raises the store's priority. Retype the stored fields out of int's alias set (`void *`, via a local view struct or a cast, one field at a time then pairs; prefer local views over shared headers). Diagnose with `-dR -fsched-verbose=6` (sched2 dump: memory dep edges between the store and the later global load). cmdCamLock matched with `void *` fields (note: the final integrated body also matches with the fields back to `int`, so the statement order found alongside mattered as much). trick_sweep family `field_alias` (cast `*(void **)&lhs` and one-field view struct forms).
- **Epilogue `ld sN` lands inside a run of stores: per-store volatile mask.** sched2 rank_for_schedule tie-break: among equal-priority ready insns one with NO dependence on the last scheduled insn beats one with an output/anti dep. Volatile stores to the same struct chain by output deps, so the independent epilogue restore jumps between them. Choose which of the trailing stores go through a `(volatile T *)` cast (no two consecutive volatile), and combine with adjacent swaps. trick_sweep family `volatile_mask` (xglRenderClearEnvInit: mechanism confirmed, 127 masks/swaps tried, best still the 1-diff body).
- **Loop bottom `move rX,rY; bnez rX; andi rX,rX,0xff` vs ours `andi; bnez`.** The target's exit test was duplicated by jump.c (duplicate_loop_exit_test) after a rotated `while`; a goto-entered do-while lets combine fold the zero-extend. Try `while (C) {B}`, `for (;C;)`, `goto test; for(;;){B test: if(!C) break;}`, `if (C) do {B} while (C);`. Plain while forms let loop.c hoist the body's constants (`li t6,92` before the loop): watch for that. trick_sweep family `loop_form` (UmlTest: not matched; goto-for1 keeps 0.9781, the while forms drop to 0.79 from the hoisting).
- **Split a reused local (s-reg where the target has a scratch reg).** A local assigned in two disjoint regions (different switch cases / sibling blocks) and live across calls in one of them gets one callee-saved s* reg everywhere. If the target uses v*/a*/t* in a region where ours uses s*, give that region its own fresh local. Matched ov12/rg_robot/_HissatuPassTime (`n` reused for the case-2 selector -> `sel`). trick_sweep family `split_local` (diff-gated).
- **Hoist a load above the condition (plain branch with a load in its slot vs our branch-likely).** reorg never fills a non-annulled delay slot with a may-trap load from the fall-through, so a target `beq/bne/beqz` whose slot holds a load means the source loaded it BEFORE the branch: `t = p->f; if (a && t) ...` (later `&&` operand or a nested if's condition into a temp). Matched _HissatuPassTime (`thread = body->shotThread[1]; if (w1 != 0 && thread != 0)`). trick_sweep family `hoist_load` (diff-gated).
- **Two adjacent stores swapped after a load in a loop: sched1 barrier.** NOTE_INSN_LOOP_BEG/END are sched1 barriers; equal priorities break on INSN_REG_WEIGHT (the store killing a reg goes first). Try: the load as the first statement after the helper call / asm, the final store in its own `do { ... } while (0);`, a fresh block-local temp instead of a function-lifetime variable (global pseudo -> $f7 vs local-alloc -> $f0). main/camera/setCFAnglePers (bodies/.../v11.c): tail matches, a v0/v1 local-alloc swap remains. trick_sweep family `sched_barrier` (diff-gated, not proven yet).
- **Narrow param type -> extra sign-extension.** A param declared `s16`/`short`/`char` gets `sll 16; sra 16` (or `andi 0xffff`) on its a-register that the target lacks: declare it `int` (and the reverse: if the target extends an a-reg we use raw, narrow the param). Matched main/nml_model_set/nmlModelDirectSend (`s16 attr` -> `int attr`). trick_sweep family `param_widen` (diff-gated, patches conflicting prototypes like void_ret).
- **Repeated small copy groups -> static inline helper.** Two or more identical-shape groups `d[0]=s[0]; d[1]=s[1]; d[2]=s[2];` written inline can give an off-by-one register allocation; outline them into `static inline void Copy3(float *d, float *s)`. Matched main/jnt/JNT_getStaticVal. trick_sweep family `copy_inline`.
- **Runs of stores of the same constant come out reordered.** `s[0] = s[1] = s[2] = 1.0f` as three statements came out last/first/second; writing them `s[2], s[1], s[0]` gave the target order. Try the reversal / permutations of the run. JNT_getStaticVal. trick_sweep family `const_rev` (diff-gated: a moved/differing store of a reg stored >= 2 times).
- **`addu` operand order, general form.** `(idx << 5) + (int)tbl` vs `tbl + (idx << 5)` swaps addu rs/rt. Commute one `+` at a time (balanced operands, not just identifiers), with and without an `(int)` cast on the pointer side. JNT_getStaticVal. trick_sweep family `addu_swap` (diff-gated on an addu with swapped rs/rt).
- **slti vs sltiu (slt vs sltu): signedness of the compared value.** Flip the compared local/param between signed and unsigned, or cast one comparison operand `(int)` / `(unsigned int)`. trick_sweep family `sign_flip` (diff-gated).
- **Drop a `ret` local that is only assigned and returned.** `ret = -1; if (...) { ...; ret = index; } return ret;` put the value in t1 instead of v0; `return index;` in the branch and `return -1;` at the end fixed it (main/sv_get_image_item/svAddImage 0.51 -> 0.93, permuter finished it). trick_sweep family `ret_local`.
- **Float compare written negated.** `c.lt.s` + `bc1t`/`bc1f` where we emit `c.le.s` (or the reverse): the source wrote `!(a < b)` instead of `a >= b` (they differ for NaN, so gcc keeps them apart). Also try the operand swap `b <= a`. Matched HitCheckUwamonoAt. trick_sweep family `float_cmp_neg` (diff-gated).
- **Re-read the field instead of a cached local.** `id = p->id; ... if (id == K)` vs `if (p->id == K)`: comparing against the re-read field changed the load/compare layout (sefCnvDeathEffectNo 0.79 -> 0.97); dropping a temp so the field is re-read also fixed ACT_loadMotion. The reverse (read a field into a local early so its load precedes a check) matched JNT_startProduction (`hoist_load`). trick_sweep family `field_reread`.
- **Pointer walk vs indexing.** `*offs++` -> `offs[i]` (nmlModelSetPartsVisible: stopped the reuse of a preloaded value); `p++` stepping -> `p = &actor[i];` at the loop top (CrossCheckActor). trick_sweep family `ptr_index`.
- **gp-relative vs lui/%lo for a global.** gcc uses `$gp` only for a global of known small size. Target `lui`+`%lo(X)` where ours is `%gp_rel(X)`: declare it unsized, `extern int X[];` (PrintThumbnail: `static int X[N]` -> `extern int X[]`; ACT_loadMotion). Reverse (target GPREL16, ours lui): give the extern its real size from config/symbols (FontTestP2). trick_sweep family `unsized_extern` (diff-gated, unsized direction only).
- **ldl/ldr/sdl/sdr instead of ld/sd: alignment.** A local struct only 4-aligned is copied with unaligned pairs; `__attribute__((aligned(8)))` on the local (or its local typedef) gives ld/sd (UwamonoBgmFunc). trick_sweep family `aligned_local` (diff-gated).
- **Bit test into its own statement.** `mode = (x & 0x40) == 0;` folds into sra/xori/andi; `flags = x & 0x40; mode = flags == 0;` keeps andi + sltiu (objDispCur); `ret = x; ret &= K; return ret != 0;` gave andi/sltu (scenarioSrcEndChk). trick_sweep family `bit_split`.
- **Adjacent field stores: write them in ascending field order, not in the asm's order.** SEQ_moveUnitSPL / SEQ_rotateUnitSPL: target stores 0x20,0x28,0x24 came from `p->x = ..; p->y = ..; p->z = ..;` (mirroring the asm order gave the 4-word diff). trick_sweep family `store_sort` (all orders of <= 4 adjacent stores to one base).
- **Global read-modify-write through a local.** `index = g; index--; g = index;` instead of `g--;`, and a clamp `c = x < 0 ? 0 : x; g = c;` (MAP_serach). trick_sweep family `via_temp`.
- **Function-local statics are `X.N` in the original.** splat names them `X_N`; write `static T X = ..;` inside the function, not a file-scope `static T X_N` (same bytes, but mapcheck fails "original symbol not defined by the C object"). integrate.py moves it automatically (`LOCAL_STATIC_FIX`).
- **GCC nested functions (`glabel parent.N, local`, entry reads $v0 = static chain) cannot be matched alone.** They need the parent decompiled with the nested definition inside (ListMake.3 -> MenuShopInfo?). next.py / permute_queue / trick_sweep skip them (`nested` in queue.json; `next.py --key` prints the reason under `skipped`).
- **Boolean as if/else.** `x = (a == b);` vs `if (a == b) x = 1; else x = 0;` compile differently (scenarioBatExecDst). trick_sweep family `bool_ifelse`.
- **Wrap-the-rest if -> early return.** `if (a || b) { ...rest... } return r;` vs `if (!(a || b)) return r; ...rest...` (scenarioSrcEndChk). trick_sweep family `early_return` (the reverse is `single-exit`).
- **Switch cases that each `return` a float: one `ret` + single return.** Per-case `return E;` put the result straight in $f0 (CheckCornerDist 0.81); `ret = E; break;` in every case and one `return ret;` after the switch kept $f20 and the trailing `mov.s` -> match. trick_sweep family `single-exit` (now also emits this switch/break form).
- **Last register swap from call-arg setup order.** ACT_setParent2: rewritten in sibling ACT_setParent's style, the final swap was only the order of the tail statements (the scheduler hoisted an `a1 = 0` arg setup). Pre-screen statement orders with `snippet.py`; `stmtswap` / the permuter's reorder pass cover it.
- **`glabel NAME, local` -> the function must be `static`.** Otherwise integrate's rebuild is byte-identical but mapcheck fails "C symbol differs from original" (bind 0 vs 1). integrate.py now adds `static` to the body automatically (try_fn reports `binding_fix`); don't spend runs on it. - Other one-off fixes from 2026-10-06 (do these by hand, not automated): a float view of a field so a zero store is not merged into `movn` with the other store (nmlModelSetTexMap); `do {} while (swapped)` -> `swapped = 1; while (swapped) { swapped = 0; ... }` (nmlModelStealthEntry); switch cases routed through shared `one: ret = 1;` / `zero: ret = 0;` labels to avoid sltu and get bc1fl (UwamonoAreaCheck); sibling inline helpers instead of hand-written stores (SGsRestoreEnv); calling a void-declared function through `(int (*)(...))` when the target uses its return value (HitCheckNyuru); 64-bit prototypes / literals copied from sibling TUs (curEnvMake); `void *` element type -> `int` so it aliases an int stack store, read through `*(int *)` (curPosProc); one counter for two loops and `do { i--; } while (i >= 0)` -> `for (i = 0; i < 64; i++)` (ACT_initSequence); goto structure -> for loops with break and a single return (EW_addComponent); output through `float *out = unit + 0x10` (SEQ_transCNSUnitChr); reuse a dead param instead of a new local (objDispCur).
- **Loads hoisted above a store: a sched1-only block barrier.** Target `sw update; lw flags; lb printflg` where ours hoists the loads above the `sw` (a pure move of loads): sched1 sees no dependence (different alias sets / the fixed-scalar-vs-struct rule), so give it a block boundary that is gone by final output. `{ float _sb = p != 0; if (_sb) {} }` (or a float local that is reassigned later, `new_var = unit != 0;`) keeps a conditional jump alive through sched1 (the float store-flag expands to a branch; flow deletes the dead sets only after the jump passes ran) and the post-reload jump pass deletes it. An empty `if (p) {}`, an int store-flag, `do {} while (0)` or a never-read float do NOT work. Matched InitShopSymbol (barrier right after the `update` store) and InitEvsSymbol / InitRetSymbol (C order `update` store, barrier, `count = 0`, flags: the store that came first moved after the barrier). - **Load width/sign differs (lhu vs lbu, lh vs lhu):** cast the dereference, `*(unsigned char *)dataTecGet(x)` (counterProc), rather than redeclaring the callee. - **sched2 equal-priority tie-break, read it before chasing it:** rank_for_schedule (gcc 2.96 haifa-sched.c) = priority, then (sched1 only) register weight, then the class w.r.t. the last scheduled insn (data-dependent with latency > 1 loses), then **the insn with MORE dependents** (`INSN_DEPEND` count, anti/output deps on reused hard regs included), then original order. main/end_print FontTexChange / endPrintWinTexLoad: the Env[8] `or` (reads a2/a3, both reused later as call args `li a2,24` / `move a3,zero`) has 6 dependents vs the Env[4] `or`'s 5, so it is scheduled first and its `sd` lands before Env[4]'s. Not cracked yet (see the bodies' notes).
- **Write the context struct, not raw offsets.** FontTexChange's first parameter is the TU's `EndPrintContext *` (`context->packet`, `context->scratch`, like its sibling FontTexReload): with that the `*pkt` reload lands where the target has it.
- **Absolute address in the target, symbol in ours (`lui 0x36; addiu 11904` vs `%hi/%lo(CfCameraDefine)`):** identical after linking; try_fn reports it as `abs_reloc` (part of `match_after_link`), `unresolved_words` counts what is really left (GameCameraReset: 2 words, a `lui`/`lbu` swap).

- **Branch-likely bit on a `return K;` path: route it through a label at the end.** `else { return 0; }` -> `else { goto zero; } ... return x; zero: return 0;` turned the last `beqz` into the target's `beqzl` (MenuFaceEpidGet). trick_sweep family `fallthrough_bl` (diff-gated on a likely-bit-only branch flip; same candidates as `fallthrough_label`, incl. the new `goto-tail` form).
- **Raw-offset stores into a global re-materialize `lui %hi(G)` per access.** `*(long long *)((char *)&G + 0x38) = v;` -> a typed view `((View *)&G)->f38 = v;` keeps the %hi base in one register (Check_Undu 0.78 -> match; one struct type per offset matched, a union of them did not). trick_sweep family `global_field_view` (diff-gated: more `lui %hi(S)` on our side). - **Re-assign a base pointer before a later loop.** `n = w->node;` again right before the third loop stopped gcc CSE-ing the value across loops (subTreeLineDraw_type_3). trick_sweep family `reload_base`.
- **if / else-if chain on one variable -> `switch`.** tskFileEx: an outer `switch (task->state)` gave the target's branch shape (0.92 -> match). trick_sweep family `if_to_switch` (also `V == a || V == b` -> two case labels; arms with a free `break`/`continue` are skipped).
- **One pointer local reassigned per target block.** `drill->effect2->hidden = 0; save->effect1->hidden = 0;` -> `effect = drill->effect2; effect->hidden = 0; effect = save->effect1; effect->hidden = 0;` (DrillPowerOffFunc); per-qword `q = &p[4]; q->x = ..; q = &p[5]; ...` instead of `p[4].x` (sprt_put: flat `p[N]` or inline helpers hoist the bases into s-regs). trick_sweep family `reuse_ptr_local` (one `__typeof__` local per same-field / same-shape cluster, or a block-scoped pointer per run).

## Plateaus: don't burn runs on these
These rarely respond to source edits. If the only remaining diff is one of these, write down the best score and stop.
- **Second scratchpad base derived with `ori reg,0x30` from the same register** (o486 MenuModelDirectSendZClear, 0.716): target `lui v0,0x7000` then `ori v1,v0,0x30` for the second base; every C form the worker tried gave a fresh `lui` (untested ideas: `(u32)base | 0x30` on the same local, a pointer derived from the first base inside one expression). Unsolved; note it and move on unless you find the form.
- **Caller-saved register swap inside one block at opcode_score 1.0** (o489 GameResourceAlloc 0.8667): decl order, temps, and statement order did not move it; leave it to the permuter.
- **Register-allocation rotations with opcode_score = 1.0 are NOT always a plateau.** Caller-saved swaps inside one block (lo/hi in t1/t0, a2/v1 in buf setup) usually are: decl order, temps, init order and int vs u32 did nothing. But s-reg rotations (s2/s3/s4) of values live across a loop or calls are often a global-alloc priority near-tie: run the `-dl` diagnosis above before giving up, and reorder statements to change the tied live ranges.
- **One `lui/addiu/addu` scheduled before or after a store**, or a few `addiu` base computations in a different order (MAP_createUnitPeer, subMWModeExSet at 0.98).
- **Prologue delay-slot filling**, i.e. which init lands in the `jal` or `bnez` delay slot (CheckSensiCommand 0.93).
- **Branch-likely forms** (`beqzl`/`bnel` vs a plain branch; try the fall-through label tricks above first) and `slti` vs `sltiu` coming from `(x-K)&0xFFFF < N`.
- **`jtbl_*` / `D_*` vs `.rodata` relocation names are NOT a blocker.** integrate's data carve gives the compiled C's own jump table / literals the original address automatically. If try_fn still says match:false, look at `differing_words`: those are real code diffs to fix. (The named-double case: `extern double` gives a wrong GPREL `ld`, `extern const double[]` gives `lui v1` not `lui at`; prefer plain literals + carve.)
- **VU0/COP2 code** (`lqc2/vadd/sqc2`), `sync`, system ops. It can't be matched in pure C, and inline asm is banned, so skip it (next.py no longer hands such functions out: queue `asm_blocked`).

## Tooling gotchas
- **False %lo relocation**: target `addiu t0,t0,%lo(D_70000010)` [LO16, imm 0] vs ours `addiu t0,t0,16`, and the `lui t0,0x7000` feeding it has NO HI16 reloc: splat symbolized a plain immediate. Linked bytes are identical; try_fn reports `"match_after_link": true` + `false_lo16` -> run `integrate.py --skip-try`. Don't "fix" the C (nmlPacketAddScreenClear).
- **`"match_pending_jtbl": true` is a match.** When the only differing words are jump-table lookups (target `%lo(jtbl_XXXXXXXX)`, ours `%lo(.rodata)+N`; opcode_score 1.0, relocs_match true) try_fn prints `match:false` but sets `match_pending_jtbl` (and `link_check`) with a "MATCH PENDING" note: run `integrate.py --skip-try` (nmlModelDirectSend: 0.9683 by score, integrate matched byte-identical). The sweep, permute_queue and permute_fn treat it as a match and integrate automatically.
- try_fn can print `match:false` when the only differences are relocation names. integrate.py can still pass in that case (its whole-file check is the real gate), so if every remaining diff is a reloc name, run integrate.
- **gcc ICE in `reload_cse_simplify_operands`** on a 16-byte struct (BLK) copy: try_fn matches but integrate fails in the full TU. Known case: PoBonusCardAnime. Report it and stop.
- If integrate of a sibling in the same TU breaks your compile, fix the body (e.g. a macro name leaking, like `msg` vs `MWMSG`). Don't touch src/.
- If a header moves mid-session and `compile_base` errors with "No such file", stop and report it. Don't create headers.
- If a `.best.json` score doesn't reproduce with `.best.c`, it is stale. Report it.
- Restore the body file to the best-scoring version before you finish.
